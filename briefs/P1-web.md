Build:
1. Next.js App Router + TypeScript + Tailwind in web/, exact pinned versions. `dev`/`start` bind 127.0.0.1 (`-H 127.0.0.1`). next.config rewrites /api/:path* to http://127.0.0.1:8000/api/:path*. `gen:types` generates web/lib/contracts.gen.ts from ../fixtures/schema/*.json with json-schema-to-typescript; commit it; app code imports types only from it.
2. Two clients: lib/api.ts (all /api calls, typed); lib/storage.ts (sends exactly the pre-signed POST fields from CreateScanResponse.uploads[i] to its url, file last, no extra headers; assets load from signed URLs as given). lib/sse.ts: fetch + eventsource-parser for the SPEC 4.8 wire format (`event: <name>`, `data: <json>` = payload without the `event` field; for `card`, data is {type, payload}). Progress: GET /api/scans/{id}/events emits `event: scan` with a full Scan; ignore `: keep-alive`; reconnect with backoff and re-read GET /api/scans/{id}.
3. Routes (SPEC 2.1): landing + demo gallery (GET /api/demo-scans); /scan/new (SPEC 2.2: capture=environment input plus ordinary picker, drag-and-drop, optional MediaRecorder, board instructions: print at 100%, check with a ruler, lay flat beside the object; duration 10-90 s and 500 MB pre-checks; HDR tip; POST /api/scans, storage upload, POST /api/scans/{id}/start); /scan/[id]; /scan/[id]/part/[partId].
4. Viewer: react-three-fiber, three pinned, @sparkjsdev/spark exactly 2.4.0. One SparkRenderer created with r3f `gl`, added to the scene, disposed on unmount; SplatMesh for the .spz URL. ONE parent group, matrixAutoUpdate=false, matrix = Matrix4().set(16 row-major values of scan_to_web.matrix).multiply(Matrix4().makeScale(s,s,s)) with s = unit_scale; splat, part GLBs, CAD STL and measure points are its children. Splat/mesh toggle (hidden when splat_uri is null), hover/click picking with outline, exploded slider, two-click measure (POST /measure, mm), manual scale (two clicks + known length, default 85.60 mm, POST /scale with expected_revision), CAD overlay at placement (translate_mm + rotation_quat [x,y,z,w]), focus animation on part chip click. A 404 asset shows a message, never crashes.
5. Parts panel: label, confidence, thumbnail; each dimension with scan / snapped (+snap_rule) / caliper and which is preferred (resolve DerivedDimension via derived_from + factor); rename (PATCH label), merge, caliper entry per feature Measurement (PATCH measurements[{feature_id, field, caliper_mm}]).
6. Chat: POST /api/scans/{id}/chat via lib/sse.ts; markdown; [[part:pX]] chips wired to viewer; highlight events; cards RepairPlan (steps with checkboxes, safety, tools), PartsToBuy (price, qty, links, total), CadResult (preview, required checks pass/fail, advisory values incl. not_computed reason, param sources, print settings, STL/STEP download, show-in-viewer, STALE banner when stale).
