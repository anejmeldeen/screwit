2. cad/service.py (CadService.run, SPEC 4.6/4.7/6.4): validate (template exists, params in range, mates resolve to a compatible feature: knob mates d_shaft or cylinder); clearance must equal the profile's for the fit type (reject otherwise); build; place (translate + quat [x,y,z,w]). Exports via Storage under scans/<id>/cad/<cad_id>/: STL (mm), STEP, model.py (template source + params), preview PNG rendered headless on CPU (test non-empty), print_settings with volume_formula estimates. input_revisions from the request; stale=false. codegen mode: status error "codegen is not enabled".
