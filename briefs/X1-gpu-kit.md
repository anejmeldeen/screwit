# X1 GPU verification kit (worktree screw-it-wt/gpu, branch ws/gpu)

Read: briefs/common.md, AGENTS.md, SPEC.md 1.5, 3.1, 6.1 steps 1-6, 6.2 steps 1-2, 10 (GPU rows).

You own only gpu/ (top-level). Create nothing elsewhere. Launch NO cloud resources; this kit is run later by a human on a GPU host.

Purpose: the dev machine has no GPU, so the real model calls cannot be tested here. Build a self-contained kit that, on a fresh AWS g5.xlarge (A10G 24 GB) or similar CUDA host, proves the real models work on a real phone video and produces numbers we can compare with the CPU path.

Build:
1. gpu/README.md: exact runbook. Launching a g5.xlarge in a non-production account with NO public inbound (SSM Session Manager only; IAM instance profile with AmazonSSMManagedInstanceCore; IMDSv2 required; encrypted root volume), a recommended AMI family (AWS Deep Learning Base GPU AMI on Amazon Linux 2023 or Ubuntu; verify the current name from AWS docs and cite the URL), copying the repo and the video up through SSM or S3, running the kit, copying results back, and terminating. State cost per hour from the current AWS pricing page with the URL and date read, or say you could not confirm it.
2. gpu/setup.sh: idempotent environment setup on the GPU host (uv, Python 3.12 venv, torch for the host's CUDA, Depth Anything 3 from its official repo with the pinned gsplat commit its README names, MapAnything, SAM 2, Grounded SAM 2, weight downloads to a cache dir). Every package and commit pinned; every install command taken from the official READMEs (cite them in comments). Fail fast with a clear message if nvidia-smi is missing.
3. gpu/smoke.py: given a video path (and optional board spec), runs: frame extraction (call screwit.recon.frames if importable, else its own minimal ffmpeg extraction, documented), Depth Anything 3 DA3NESTED-GIANT-LARGE-1.1 with infer_gs=True, ref_view_strategy="middle", export_format="mini_npz-gs_ply" at 32, 48 and 64 views, recording peak torch.cuda.max_memory_allocated, wall time, output shapes, extrinsics convention check (world-to-camera: camera centres from -R^T t lie on a plausible orbit), prediction.scale_factor and whether the gaussians attribute is `prediction.gaussians` or under `aux` (SPEC 6.1 step 2 says P2 must confirm this). Then MapAnything (facebook/map-anything-apache) on the same frames with the same measurements. Then SAM 2 video predictor with a centre box prompt and Grounding DINO with a text prompt, recording memory and time, after freeing DA3 per SPEC 6.1's VRAM rule and asserting memory dropped. Writes gpu/out/<run>/report.json and report.md with every number.
4. gpu/compare.py: given report.json and caliper readings (JSON: name -> mm), runs the repo's scale and measurement code if importable (screwit.recon.scale, screwit.perception) on the saved outputs and reports scan vs caliper error. If those modules are not importable yet, it says so and skips that section.
5. Tests you CAN run here: shellcheck setup.sh if available (install via pip shellcheck-py if needed), ruff on Python, and a dry-run mode (`smoke.py --dry-run`) that exercises argument parsing, report writing and the free-VRAM logic with torch absent, tested under pytest in gpu/tests/ (run with the main venv).

Report also: every upstream API name you relied on and the doc URL that confirms it; anything you could not confirm.
