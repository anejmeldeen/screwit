# P2 recon: feed-forward reconstruction (worktree screw-it-wt/recon, branch ws/recon)

Read: briefs/common.md, AGENTS.md, SPEC.md 1.5 (no training, no per-scene optimization: add none), 3, 3.1 (camera contract, transforming gaussians incl. DA3 nested scale_factor quirk and quaternion orders, SPZ packing), 3.2, 4.1, 4.2, 5 (/scale), 6.1 (all), 7 P2, 10. Then backend/screwit/contracts/models.py and backend/screwit/interfaces.py (implement ReconPipeline; raise StaleRevision).

You own only backend/screwit/recon/, backend/tests/recon/, scripts/make_fixture_splats.py, fixtures/scans/*/splat/.

Adapters: Depth Anything 3 (DA3NESTED-GIANT-LARGE-1.1, infer_gs=True, ref_view_strategy="middle", export_dir, export_format="mini_npz-gs_ply", export_kwargs gs_views_interval; docs: https://github.com/ByteDance-Seed/Depth-Anything-3/blob/main/docs/API.md) and MapAnything (facebook/map-anything-apache, memory_efficient_inference=True, invert camera-to-world; https://github.com/facebookresearch/map-anything). FakeGeometryModel for CPU tests: synthetic scene (meshes + ChArUco board texture) and cameras, CPU-rendered model-grid images and depth, returned in an unknown similarity frame, reproducing DA3-nested's quirk (depth and extrinsic translations multiplied by scale_factor, gaussians not) so your correction is tested.

Build:
1. frames.py: probe, fps from duration so 48-64 keyframes survive dropping the blurriest 30% (Laplacian variance), zscale+tonemap for HLG/PQ 10-bit, full-res + model-grid copies (long side 504, each side rounded to a multiple of 14, per-axis mapping in frames.json); photos: EXIF orientation + one size. ONE ffmpeg helper with timeout and rlimits (preexec_fn); use `unshare -rn` or bwrap for no-network if they work unprivileged, else record that. Test with a synthetic video you generate.
2. geometry.py: protocol, both adapters, fake, conversion to Cameras/CameraFrame (world_to_camera row-major, OpenCV).
3. scale.py: ChArUco 5x7, 30 mm squares, cv2.aruco.CharucoDetector on full-res frames, map to model grid, multi-view triangulation (pixels with P=K[R|t], no undistortion), RANSAC+Umeyama to board coordinates, Z from support plane (Open3D segment_plane), board tilt >10 deg flags and falls back to object_bottom_center, learned-scale fallback, residual/corner flags. recon/board.py writes a printable A4 300 dpi PNG with an X-axis arrow.
4. gaussians.py: 3DGS PLY read/write ([w,x,y,z], log scales, inverse-sigmoid opacity, f_dc), similarity transform, nested scale_factor correction, crop bbox+10 mm, opacity prune, voxel downsample to 1.5 M cap; SPZ writer per https://github.com/nianticlabs/spz README (PyPI binding is broken here), a version Spark 2.4.0 reads (record which), no coordinate conversion, rotations in spz's [x,y,z,w] layout. Verify against an INDEPENDENT decoder: (a) build Niantic spz C++ from source in $KIROCREW_SCRATCH if a compiler exists, else (b) Spark 2.4.0's decoder under node without WebGL, else (c) another independent reader; report which. Golden: one elongated gaussian of known rotation round-trips with correct orientation.
5. tsdf.py: Open3D 0.19 ScalableTSDFVolume fed METRES (depth and translations mm->m, depth_scale=1.0, depth_trunc=1.5, convert_rgb_to_intensity=False, voxel_length=0.001, sdf_trunc=0.004, RGB8), vertices back to mm, largest component, pymeshfix, web GLB <200k tris, full mesh kept. Golden: synthetic 100 mm cube from >=4 poses returns 100 +/- 2 mm per side.
6. pipeline.py: stage order frames->geometry->scale->object_mask->splat+mesh->parts, calling PerceptionService.object_mask and .parts (fake in tests), progress for every transition, artifacts via the Storage protocol per SPEC 3.2 (tmpdir fake in tests), VRAM release helper (torch optional), no-board origin fixed after object mask and before splat/mesh are written. rescale(): analytic per SPEC 5 /scale, StaleRevision on mismatch, calls perception.rescale_parts.
7. scripts/make_fixture_splats.py: for each fixtures/scans/<id>/mesh/object.glb (P3 makes these later) sample <=200k gaussians on the surface, write splat/scene.spz; if absent, say so and exit 0. Test on your own mesh.
8. End-to-end CPU test: fake model + synthetic scene with a board -> reconstruction.json validates, known object measures within 2%, cameras.json validates, splat decodes.

Report also: SPZ version and independent decoder used, ffmpeg containment actually achieved.
